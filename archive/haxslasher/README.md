# 少女 vs スライム：戦闘手触りプロトタイプ

最終製品は Unity 6 で作る Windows / Android アプリです。このブラウザ版は、Unityへ移す前に攻撃の反応、敵の硬さ、ゲージの回り方、報酬の見え方を短時間で調整するための試遊機です。

## 起動

まずは `index.html` をブラウザで開きます。ローカルファイルの制限が出る場合は、このリポジトリのルートで次を実行し、`http://localhost:8000/archive/haxslasher/` を開きます。

```powershell
python -m http.server 8000
```

旧サバイバー型プロトタイプは `legacy-prototype.html` に残しています。

## 今回試すもの

- 青髪、赤い羽織、橙色のスカート、刀を持つ主人公
- 通常時は刀を納めた少女の3方向（下・横・上）アニメーション
- 移動開始は歩き、同じ方向を0.65秒保持すると走りへ切り替え（左向きは横向きを反転）
- 3方向の抜刀斬りと、スライムの待機・溜め・飛び込み攻撃アニメーション
- 3方向×4コマのジャンプ、空中なで斬り、急降下突き専用アニメーション
- スライム1体ずつとの戦闘
- ジャンプ、空中なで斬り、着地衝撃波と0.48秒の硬直、剣、0.8秒チャージの回転斬り、0.65秒チャージの氷魔法
- `Rituals of the Jade Valley`を戦闘開始後にループ再生（BGM ON/OFF・音量保存）
- 空振りの合成風切り音、`katana-slash1.mp3`の命中音、`magic-wind2.mp3`の魔法音と、Web Audioで補う必殺・着地・敵・報酬効果音（SFX ON/OFF・音量保存）
- 1体につき EXP 1、Gold 1、スライムゼリー 1
- 3 EXP で Lv 2、5体討伐で結果表示
- 開始ボタンを押すまでは安全に説明と調整数値を確認
- 画面上の「調整」から戦闘値を変更（敵の値は再生成後に反映）

## 操作

| 操作 | キーボード | 画面 |
| --- | --- | --- |
| 移動 | `WASD` / 矢印 | 方向パッド |
| ジャンプ | `Space` | ジャンプボタン |
| 剣 / 空中なで斬り | `F` | 剣ボタン |
| 急降下突き | 空中で`S` / `↓` | 空中で下ボタン |
| 回転斬り | `Q` | 回転斬りボタン |
| 氷魔法 | `E` | 氷魔法ボタン |

ゲームパッドにも対応しています。左スティック / D-padで移動、Aでジャンプ、RTで地上斬りまたは空中なで斬り、空中で下入力すると急降下突き、Xで回転斬り、Yで氷魔法です。同じ移動方向を0.65秒保持すると歩きから走りへ変わります。回転斬りと氷魔法は1回押すとチャージを開始し、完了後に自動発動します。

BGMは最初のクリック・キー入力または戦闘開始時に再生を試みます。標準Gamepad入力だけではブラウザの自動再生制限を解除できない場合があるため、その場合は画面上部の`BGMを再生`を一度押してください。ON/OFFと音量はブラウザに保存されます。

効果音も初回だけブラウザの音声許可が必要です。画面を一度クリック・タップするかキーを押すと有効になります。Steam Controllerだけで開始して鳴らない場合は、画面上部の`SFX待機`を一度押してください。短い確認音が鳴って`SFX ON`へ変わります。BGMと効果音は個別に音量を変更できます。

## Steam Controller

ブラウザ版ではSteam Input固有APIを直接使わず、Steam Inputが作る標準ゲームパッド入力をGamepad APIで受けます。画面の`INPUT`表示で状態を確認できます。

| Steam Controller | ゲーム操作 |
| --- | --- |
| 左パッド / Stick | 移動 |
| A | 戦闘中のジャンプ |
| RT | 剣 |
| X | 回転斬り |
| Y | 氷魔法 |
| A / Menu・Start | 待機・結果画面の開始／リトライ |

最初の設定:

1. Steamへ使用中のEdgeまたはChromeを「非Steamゲーム」として追加する
2. そのショートカットのコントローラーレイアウトで`Gamepad`テンプレートを選ぶ
3. Steamからブラウザを起動し、この試遊ページを開く
4. ページを選択してコントローラーのボタンを一度押す
5. 画面のPAD表示が`接続済み`になったことを確認する

`要設定`と出る場合は、raw入力のボタン番号を推測せず停止しています。Steam Inputの`Gamepad`テンプレートを選び直してください。

標準ゲームパッドとして認識されない場合の予備設定は、左パッド=`WASD`、A=`Space`、RT=`F`、X=`Q`、Y=`E`、Start=`Enter`です。このLegacyキーボード設定でも既存操作をすべて使えます。

Steam Controllerで操作できるのにGamepad APIへ機器が出ない場合、画面表示は`KEY / Legacy`になります。Steam Inputが物理ボタンをキーボードやマウスへ変換している状態で、故障や切断ではありません。ブラウザから物理機器名までは判別できません。

### ボタン配置の変更

`Steam Controller`パネルの`ボタン配置を変更`を開きます。

- `PAD`列: 変更を押してからStandard Gamepadのボタンを押す
- `KEY / Legacy`列: 変更を押してからSteam Controllerが出力しているキーを押す
- 入力待ちは`Esc`、同じ変更欄の再押下、またはパネルを閉じるとキャンセル
- `配置を初期状態へ戻す`: A、RT、X、Yなどの初期値へ戻す

変更した配置は上の現在配置にも反映され、ブラウザのlocalStorageへ保存されます。次回の再読込後も維持されます。Steam Input Legacyで物理ボタンそのものの出力を変える場合は、Steam側のコントローラーレイアウトでも変更できます。

## 最初に見てほしい5点

1. ジャンプ高度、空中斬り、急降下突き後の硬直
2. スライムが硬すぎるか、柔らかすぎるか
3. 回転斬りの0.8秒チャージと360度攻撃の手触り
4. 氷魔法の0.65秒チャージとMP消費に価値を感じるか
5. PCとスマホ想定のボタン配置が操作しやすいか

数値を一度に変えすぎず、2～3項目ずつ調整して手触りを固定します。調整パネルを開いている間は戦闘が一時停止します。決まった仕様は `../docs/first-combat-slice.md` を正としてUnityへ移します。

報酬・レベル・ゲージの自動確認は次で実行できます。

```powershell
node .\archive\haxslasher\smoke-test.cjs
```

## MVPの外側

今回まだ入れないものは、セーブ、Googleログイン、CoffeeLearning同期、ショップ、クラフト、装備、複数敵、ボス、より多コマの本格アニメーションです。刀命中音と魔法音は指定素材へ差し替え済みで、残る合成音は戦闘の手触りが固まった後に本番音源へ置き換えられます。
