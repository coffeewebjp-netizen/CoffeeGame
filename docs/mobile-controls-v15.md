# Android / タッチ操作 V15

既存のUnity Android版（2026-08-16開発APK）とInput Systemのタッチ入力を拡張する。PCで採用した赤羽織の剣の少女、V14猫モーション、2体の敵、共闘、防御・ジャスト回避などを同じシーンからビルドする。キャラクターの再生成やセーブ形式の変更は行わない。

## Androidで開始

開発用APK: `unity/CoffeeGame/Builds/Android-MobileV15/CoffeeGAME-MobileV15-development.apk`

1. APKをAndroid端末のダウンロードフォルダなどへコピーする。
2. 端末のファイルアプリからAPKを開く。初回は、そのファイルアプリからのインストールをAndroidの案内に従って許可する。
3. CoffeeGAMEを起動し、入力方式で「タッチ（画面操作）」を選んで開始する。横持ちで操作する。

Android 8.0（API 26）以上、ARM64向けの開発ビルド。ストア公開用ではない。以前のAPKは `Builds/Android/CoffeeGAME-development.apk` に保持する。古いインストールとの更新可否は署名と端末側の状態による。更新拒否時に既存アプリを削除せず、先に進行データを書き出す。PCの進行が新規インストールへ自動で複製されるわけではない。既存の書き出し／取り込み、保存先設定を利用する。

## タッチ操作

| 操作 | 指の動かし方 |
| --- | --- |
| 移動・走行 | 左半分の空きを触ってスワイプし、押したまま保持。大きく倒すと走行 |
| カメラ | 右半分のボタン以外をスワイプ |
| 通常攻撃 | 剣は「斬る」、猫は「連弾」 |
| 魔法／必殺 | 「魔法」「必殺」。猫は「大魔法」「時止め」 |
| 回避／ジャンプ | 「回避」「跳ぶ」 |
| 防御 | 「防御」を押し続ける |
| 防御ジャンプ | 移動方向＋防御を保持し、別の指で「跳ぶ」。既存の側転・バク転判定を使用 |
| 落下突き | 剣の少女のジャンプ中に移動を下へ倒す |
| ロックオン | 「固定」で近い敵を固定。「解除」で解除 |
| 操作キャラ | 「切替」。加入・出撃済みの仲間へ切替 |
| 一時停止／設定 | 右上「ポーズ」。メニュー内もタップで操作 |

ボタンは画面のセーフエリアに合わせ、解像度・横長比率で大きさを調整する。移動・カメラ・各ボタンは別々の指で同時操作できる。押し始めた役割を指を離すまで維持するため、移動の指が攻撃ボタンへ滑っても攻撃しない。ポーズ、非表示、アプリの中断・フォーカス喪失、画面サイズ変更で入力を解除し、復帰後は一度指を離して操作を再開する。

## 開発と検証

`CoffeeGame.Editor.BuildCoffeeGame.BuildAndroidMobileV15NoSetup` は既存シーンをARM64/IL2CPP開発APKとして出力する。既存キャラクターを上書きするセットアップ処理は呼ばない。開発署名を使い、一時的なバックエンド等の設定は復元する。Windows確認用は `BuildMobileControlsV15NoSetup`。`-captureMobileControls <folder>` は開発版専用で、メモリ内の仮プロフィールと仮想Touchscreenを使用する。

端末のノッチ・発熱・フレームレート・実際の指での押しやすさ・中断復帰は、対象Android端末での確認が必要。Windows上のタッチ注入確認をAndroid実機テストとは数えない。
