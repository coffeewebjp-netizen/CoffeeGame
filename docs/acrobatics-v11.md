# 2体の敵・接地した回避・バク転（Acrobatics V11）

ORC-20260906-005 / 2026-09-06。Defense V10を基にした、元へ戻せるローカル更新。

## IN03：プレイ確認後の修正

- 落下突きでは、胸を起こす補正を弱め、上半身を前へ倒す。頭は立位の顔方向を基準に下へ向け、両脚を外へ開いてしゃがむ。刀先の接地と約1秒の硬直を維持する。
- 停止・歩行中の回避は低い前転。走行中は以前のDodgeクリップとジャンプ軌道を使う回転跳び。入力時に種類を固定し、回避中の方向変更で切り替えない。走行は従来どおり同方向入力を約0.65秒継続した状態。移動入力を離して回避した場合は前転となる。
- 防御＋後方ジャンプは採用済みのバク転を維持する。防御＋左右ジャンプは向きを保った側転跳び。前後左右はキャラクターの向きを基準とする。後ろ寄りの斜め入力はバク転、横寄りの入力は側転。どちらもジャンプとして扱い、回避無敵・ジャスト回避報酬を付けない。
- 今回の修正だけ戻す復元ツールは tools/restore-pre-acrobatics-v11-revision-02-player.cmd。ゲームを終了してから使用する。進行セーブは巻き戻さない。さらにV10へ戻す場合は、まずこの修正を戻してから従来のV11復元ツールを使う。

## 初回V11の操作と動作

- 戦闘には2体の敵が同時に登場する。最初はゴブリンとスライム。倒れた敵は従来の消滅待ち時間の後で補充する。各敵の経験値・報酬は1回ずつ計上し、5体ごとのライバルへの遷移時には戦闘中の敵を片付ける。
- 剣の少女はジャンプ中に下を新しく入力すると落下突き。着地で腰を深く落とし、両膝を曲げ、刀を真下へ突き立てる。着地後約1秒は移動・攻撃・ジャンプ・回避を受け付けない。衝撃波のダメージは1回だけ。
- 防御を構えたまま、キャラクターが向いている方向の後ろへ入力してジャンプするとバク転する。後方へ実際に移動し、向きは維持する。ジャンプの音を使い、回避無敵やジャスト回避のゲージ報酬は付けない。
- 通常回避は0.62秒の低い前転。物理的な跳ね上がりは約6cm。背中・腕・脚を丸めて回転し、途中で足が床へ触れても回避動作を打ち切らない。既存の回避無敵とジャスト回避の判定時間は維持する。
- 防御の初期設定はG / LT。回避・ジャンプは既存の割当を使う。防御中の後ろは画面の固定方向ではなく、キャラクターの向きに対する後方。

## モーションの出典と調整

Meshyの画面で「Roll Dodge」（1～4の候補）と複数の「Backflip」を確認した。保存済みV5の回避素材は`360_Power_Spin_Jump`で、今回の低い前転には合わない。

今回使用するのは、既存モデルと骨格に重ねるプログラム制御のポーズ。Meshyから新しいクリップをダウンロードしたものではない。髪・服・体型・既存FBX・コントローラーはこの更新で変更しない。回転の終了時は短い角度で元の姿勢へ戻し、逆向きに一周巻き戻さない。

調整箇所は`CombatTuning`の`groundRollSeconds`、`groundRollHopHeight`、`guardBackflipHeight`、`guardBackflipSpeed`、`plungeRecoverySeconds`。描画上の膝・腰・腕の曲げは`AcrobaticMotionPresentation`と`DefensePosePresentation`で調整する。ポーズと移動は戦闘時計に従い、ポーズ・時間停止で進行を止める。

## 必殺技の掛け声

音声ファイルはOwnerが作成する。今回は音声を生成せず、成功した必殺技の発動時にキャラクター別に再生する受け口だけを用意した。音声が未配置でも必殺技は通常どおり動作する。

配置先は`Assets/CoffeeGame/Resources/Audio/Voices/Heroine/special_01.wav`と`Assets/CoffeeGame/Resources/Audio/Voices/SilverCat/special_01.wav`。Unityが読み込める形式なら拡張子は対応形式へ変更できる。主人公は溜めが完了して発動した時、猫少女は時間停止が成功した時に鳴らす。中断・退場では音声を停止する。ファイル配置後はゲームの再ビルドが必要。
