# 龍少女の操作版 V21

ORC-20260905-005 / IN12。既存の白黒・竜紋のライバル `SplitInk` を三人目の仲間として扱う。猫少女とは別のHP、MP、必殺ゲージ、成長、休息・戦闘不能状態を持つ。親密度100で加入し、T / RB / タッチの切替で順に操作する。既存の保存形式のメンバー一覧に追加し、旧メンバーや加入記録を消さない。

## 操作と初期調整値

|操作|挙動|
|---|---|
|通常攻撃|右ツメ、左ツメ、重いツメの三連撃。先行入力は残り段数まで保持。三段目は通常の3倍ダメージ、1.65倍の距離、前方180度。|
|魔法1：前龍門|対象位置に龍の輪と透明な膜を設置。敵は膜に吸い込まれ、12秒間移動・攻撃不能。被ダメージは有効。|
|魔法2：後龍門|対象の後方に二つ目の門。龍が0.9秒かけて降臨し、1.5秒ごとに敵へ攻撃。|
|魔法3：甲龍手刀一段|腕を振り下ろし、龍の光線を放つ。40m以内かつカメラ内の敵へ魔法基礎ダメージの6倍。門・龍・拘束を解除する。|
|必殺：龍の呼吸|戦闘時間60秒。移動速度、攻撃力、防御倍率、HP・MP回復量が2倍。防御倍率2は被ダメージ半減。ポーズ中は減らない。|
|空中通常攻撃|一度のジャンプにつき一度、空中のツメ攻撃。|
|空中で↓|足を下へ出して踏みつけ、半径4.2mへ0.8秒で風の衝撃波が広がる。同じ敵には一回だけ命中。|

魔法は一回につき最大MPの15%。対象はロックオン優先、なければ最寄りの敵。射程16m。対象がいない場合はMPを消費しない。前龍門段階は20秒、召喚段階は30秒で失効する。手刀後は5秒の再使用待ち時間。召喚攻撃は使用者の攻撃補正と龍の呼吸を受ける。

龍少女の戦闘中HP回復は最大HPの1/900毎秒を基準にする。龍の呼吸中は2倍。休息・戦闘不能の実時間回復は既存仕様（10分でHP1%復活、約15分で休息全回復）を使う。強化と龍門はセーブせず、戦闘終了・戦闘不能・休息・リセットで解除する。

## モデルと復元

Meshy 7の高精細カラー原型から100K三角面モデルを作成し、身長1.7mの人型リグを設定。リグID `01a090a2-b4de-73c2-9f07-17a0138c3dcd`。今回の再メッシュとリグに追加クレジット消費なし（表示3128のまま）。

`art/3d/trials/meshy-split-ink-v11/source/dragon-triangle-rig.glb` が未改変の入力。Blenderスクリプト `tools/blender/prepare_dragon_playable.py` が衣装ウェイト補正、24種類の動作、Unity用FBXを出力する。Meshyの走行データは比較用の元テイクとして保持し、今回の戦闘モーションはこのリグ用にBlenderで作成したもの。

旧キャラクターのモデルパスは置換しない。龍少女は `Resources/Models/Characters/DragonGirl` と専用アニメーションコントローラーから読み込む。確認用Windows版は `Builds/Windows-DragonGirl` に分離する。

`-dragonTrial` は三人を加入済みにしたメモリー内プロフィールで開始し、セーブファイルを書き換えない。`-captureDragon <出力先>` は同じ条件で戦闘テストと画像出力を行う。通常起動は従来のプロフィールを使うため、親密度100またはデバッグ加入が必要。

## 確認記録

- EditMode回帰テスト366件すべて成功：`Builds/dragon-v21-tests.xml`。三人の切替、保存復元、拘束解除、強化の終了、専用テクスチャ保持を含む。
- 無音のWindowsプレイヤーで実際のコマンドを実行。23項目成功、三連撃は3・3・9ダメージ。捕獲・召喚攻撃・手刀・60秒強化・ポーズ・空中命中・踏みつけ命中・リセットを確認。
- NVIDIA GeForce RTX 4070 Laptop GPUで8場面を画像出力。確認記録は `Builds/dragon-evidence-v21`、最終立体形状の確認は `Builds/dragon-evidence-tube`。画像保存時のフレーム時間を通常プレイ性能の値として扱わない。
- モデルは101,463三角面、24動作。袖・裾はウェイトを調整したが、大きな腕振り時の折れや重なりには仕上げの余地がある。渦巻きの瞳はゲーム中の距離での判読性を保証していない。龍門・召喚龍は今回のローカル生成形状を使う。

起動：`tools/launch-dragon-girl-trial.cmd`。T / RB / タッチの操作ボタンで切替可能。起動時は龍少女を選択する。音は無効、終了すると確認用の進行は破棄する。Steam起動先の更新・Androidへのインストールは今回行っていない。
