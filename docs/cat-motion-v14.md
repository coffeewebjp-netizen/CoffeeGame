# 猫少女のモーション V14

ORC-20260906-007。猫少女の動きの品質を剣の少女に近づけるため、既存の銀髪・白いコートのモデルに専用モーションを追加する。モデル、テクスチャ、能力の威力・消費・待ち時間、操作、加入・回復・保存仕様は保持する。

## 変更

- 呼吸する待機、接地を揃えた歩行・走行。走行の上半身は保存済みの猫用Meshyモーションを使用する。
- 上昇・落下・膝で受ける着地を別々のクリップにする。
- 通常魔法は右手・左手・両手の3段。大魔法は両腕を広げて持ち上げ、前に押し出す。時間停止は片手を高く掲げる専用動作。
- 走行回避は脚をたたんだ全身回転。停止・歩行時の低い前転、防御からの側転・バク転も既存の操作で使用できる。
- 被弾と戦闘不能の動きを分離し、着地・被弾の余韻は操作を再開すると切り上げる。アニメーションの再生速度は移行先クリップから求め、遷移時間は秒で統一する。

FBXのシーン初期姿勢が歩行途中だったため、スキンのbind poseから骨を復元して作成する。足と腕は2ボーンIKで解き、元の骨の長さを維持する。指・尻尾・衣服専用の骨はなく、衣服は既存のウェイトで体に追従する。独立した布シミュレーションではない。
