# 防御・パリイ・カウンター（Defense V10）

2026-09-06 ORC-20260906-003。Party V9の主人公・猫少女・仲間切替・回復・音声を維持し、防御とタイミングによる戦闘報酬、剣の少女の落下突きを追加する。

## 操作と判定

- 防御は初期設定でキーボード`G`、ゲームパッド`LT`を長押しする。タッチ画面には防御ボタンを追加。設定で変更でき、既存の攻撃・回避・仲間切替の設定値を維持する。
- 地上で行動できる時に防御でき、防御中はゆっくり移動する。攻撃・詠唱・ジャンプ・回避とは同時発動しない。主人公は刀を体の前へ構え、猫少女は両手を前へ出して魔法障壁を張る。
- 通常防御では、能力値による軽減を適用した通常被ダメージの10%を受ける。HPは既存仕様の整数で、端数は切り上げ、最低1HP。防御時は通常の被弾モーションと吹き飛ばしを抑える。
- 防御を押してから0.18秒以内に敵の攻撃を受けるとジャストガード。ダメージを0にし、攻撃した敵を1.5秒よろけさせ、その振りを中断する。防御を連打した際の再判定間隔は0.35秒。攻撃中に押しっぱなしにしても、攻撃終了時にジャスト判定を予約しない。
- 回避開始から0.18秒以内に実際の敵の命中を回避すると、操作したキャラクターの必殺ゲージを最大にする。同じ回避・同じ敵の一振りでは1回だけ。遠くの敵の予備動作や、実際に届かなかった攻撃では発生しない。通常の回避無敵時間は維持する。
- 主人公・猫少女の攻撃が、敵の予備動作または振り切るまでに命中するとカウンターで与ダメージ2倍。中断・よろけ・攻撃後の隙には適用しない。魔法弾も命中時に判定する。時間停止中は命中時の倍率を保存し、解除時に再度倍にしない。
- 剣の少女はジャンプ中に下方向を新たに入力すると落下突き。刀を下へ向けて急降下し、地面への接触で周囲へ1回だけダメージと衝撃波を出す。既存の落下攻撃威力・半径・着地硬直を維持し、猫少女に刀の落下突きは適用しない。

## 演出と調整

刀の防御は金属の火花と短い金属音、魔法障壁は青い輪と共鳴音、パリイは金色の閃光と星、ジャスト回避は青い発光と上昇音、カウンターは鋭い斬光、落下突きは地面を広がる輪・破片と低い衝撃音。音は決定的な波形合成で一度だけ生成し、通常の効果音音量設定に従う。追加の音源購入や外部生成は行わない。

実モデルのGeneric骨格を名前で解決し、アニメーションの上に防御姿勢を加える。主人公の刀の軸は刀メッシュと右手から求める。モデル本体・テクスチャ・既存アニメーションクリップは再生成しない。効果は戦闘の時計に従い、ポーズ・時間停止・仲間の退場で適切に停止または破棄する。

判定時間と防御倍率は`CombatTuning`の`justGuardSeconds`、`guardRearmSeconds`、`parryStaggerSeconds`、`justDodgeSeconds`、`guardDamageMultiplier`で調整できる。セーブ形式はversion 3のままで、進行・加入・休息の契約は変更しない。
